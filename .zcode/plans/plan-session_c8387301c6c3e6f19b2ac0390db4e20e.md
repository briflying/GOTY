# Выживание-хоррор «в духе Darkwood» — первый играбельный срез

## Решение по графике (как в самом Darkwood)
**3D-сцена + стоящие 2D-спрайты-силуэты + перспективная камера под наклоном (~55°).** Конус зрения — Spot Light с мягкими тенями (стены реально отбрасывают тени, как в оригинале). Тьма — почти нулевой ambient + туман + виньетка/зерно (post-processing). Бонус: 3D-URP проекта рабочий, а сломанный 2D-пайплайн трогать не придётся.

## Что войдёт в первый срез
1. **Игрок**: WASD-движение, прицел мышью (персонаж поворачивается к курсору), спринт на Shift с выносливостью, здоровье.
2. **Конус зрения**: тёплый Spot Light (~75°) на игроке, целится в курсор; тени от стен и деревьев; слабое свечение вокруг игрока.
3. **Камера**: плавное слежение с наклоном вперёд к курсору (фирменное « lean»-ощущение Darkwood).
4. **Ближний бой**: взмах по ЛКМ — урон врагам в дуге перед игроком, откат, отбрасывание.
5. **Враг**: AI на NavMesh — состояния Wander → Chase → Attack; ночью агрессивнее и «слышит» дальше; силуэт с красными глазами.
6. **Цикл дня и ночи** (ускоренный для теста: ~3 мин день / ~3 мин ночь): день — тусклый тёплый свет, ночь — почти чернота с синей «луной»; часы в HUD, клавиша T ускоряет время.
7. **Убежище**: домик из стен, открываемая дверь (E), лампа с миганием, окно; аптечки-пикапы.
8. **HUD** (TMP): полосы здоровья/выносливости, часы, подсказка взаимодействия, экран смерти с рестартом (R), пауза (Esc).
9. **Атмосфера**: туман, виньетка + плёнка-зерно, тёмный «мшистый» пол, генерировать буду простенький эмбиент-дрон (WAV-синтез скриптом) — этот пункт можно вычеркнуть, если что-то пойдёт не так.

## Файлы (всё в `Assets/_Game/`)
```
Scripts/
  Core/       GameManager, DayNightCycle
  Player/     PlayerController, PlayerStats, PlayerCombat, PlayerVision, CameraRig
  Enemies/    EnemyAI, EnemyStats
  World/      Interactable (base), DoorInteractable, PickupHealth, LampFlicker
  UI/         HUDController
Editor/
  GameSetup.cs   — меню «Tools/Игра/Собрать сцену»: чинит висячую ссылку в Quality
                   Settings, генерирует PNG-плейсхолдеры (силуэты, пол, доски),
                   собирает префабы, строит и сохраняет сцену Gameplay, печёт NavMesh,
                   добавляет сцену в Build Settings.
Prefabs/ Scenes/ Textures/   (создаются скриптом)
```
Плейсхолдер-арт рисуется кодом в редакторе: тёмные силуэты (капюшонная фигура, болван врага с красными глазами), шумный «мшистый» пол, «доски» для стен. Код и имена — английские, комментарии и весь UI — на русском.

## Ввод
Только новый Input System (опрос `Keyboard.current` / `Mouse.current`) — старый `Input` в проекте отключён.

## Как это будешь запускать ты (один раз, ~2 минуты)
1. Открыть проект в Unity, дождаться компиляции.
2. Меню **Tools → Игра → Собрать сцену**.
3. Нажать Play.

## Проверка
Попробую найти установленный Unity (`C:\Program Files\Unity\Hub\Editor\...`) и прогнать batch-компиляцию проекта из командной строки, чтобы поймать ошибки CS до тебя. Если редактор не найдётся — просто отдам код, а ошибки увидим при открытии.
